# HELP SYSTEM V2

This document is mandatory reading together with `PIANO_SVILUPPO_V2.md`.

The help system is not an accessory button.

It is part of the didactic engine.

## Core principle

The goal is not to reveal the answer.

The goal is to understand:

- why the student is blocked;
- which prerequisite is missing;
- which mistake was made;
- how to recover the missing concept.

The system must adapt to the student.

## Progressive help ladder

Every exercise should support as many of these levels as possible.

Level 0
- autonomous attempt

Level 1
- tiny hint

Level 2
- reminder of the relevant rule

Level 3
- first step solved

Level 4
- guided walkthrough

Level 5
- complete solution

Level 6
- immediate twin exercise with different values

## Example

Exercise:

3x + 5 = 17

Hint 1:
"The goal is to leave x alone."

Hint 2:
"Which operation removes +5?"

Hint 3:
"Subtract 5 from both members."

Hint 4:
3x + 5 - 5 = 17 - 5

Hint 5:
3x = 12
x = 4

Hint 6:
Solve 2x + 7 = 19.

## Regression rule

If the student repeatedly fails:

- stop increasing difficulty;
- identify the weak skill;
- show a micro lesson;
- provide a simpler exercise;
- provide a similar exercise;
- only then resume progression.

## Mandatory support components

- contextual hints;
- worked examples;
- common mistakes database;
- prerequisite reminders;
- targeted recovery sessions;
- mastery tracking;
- adaptive repetition.

## Important

The help system must never become:

wrong -> reveal answer -> continue.

Instead:

wrong -> understand -> repair -> verify -> continue.
